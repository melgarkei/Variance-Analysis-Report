How to Publish This Website Live on GitHub (Free)

Step-by-step visual instructions to get your live website link

Yes, you put this code into GitHub!

You save this code as a single file named index.html on your computer, upload it to a repository on GitHub, and turn on GitHub Pages. Here is the exact path:

1

Save this code as index.html

Copy this entire code block into a file on your computer and save it as index.html.

2

Create a New Repository on GitHub

  1. Go to github.com/new
  2. Type a name, e.g. pdf-extractor
  3. Keep visibility as Public
  4. Click the green "Create repository" button
3

Upload index.html to GitHub

Inside your new repository, click "uploading an existing file" (or use Git terminal commands below), drag your index.html file into the box, and click Commit changes.

git init
git add index.html
git commit -m "Initial PDF Extractor Web App"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/pdf-extractor.git
git push -u origin main
4

Enable GitHub Pages

  1. Inside your repository, click the Settings tab at the top right
  2. In the left sidebar, click Pages
  3. Under Build and deployment → Branch, select main and / (root)
  4. Click Save

Your Web App is Live!

Wait 60 seconds and GitHub will generate your live public link:
